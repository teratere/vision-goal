# 🌟 VisionGoal - ビジョンボード＆目標達成ダッシュボード

感情を揺さぶる「強烈な1枚のビジュアル」と、期限・動機・思考の着眼点という「論理」を1画面に統合した、完全クライアントサイド動作のビジョンボード＆セルフマネジメントWebツールです。  
登録した写真データやテキストはブラウザ内部（IndexedDB / localStorage）にのみ保存され、外部サーバーへの通信は一切行われません。

> **🌐 Live Demo:**  
> ブラウザですぐに使える本番公開版はこちら 👉 **[https://selfup.net/visiongoal/](https://selfup.net/visiongoal/)**

---

## 🌟 主な機能 (Features)

### 1. 魂の1枚（ビジュアルアンカー）
- **1目標につき1枚固定:** 目移りを防ぎ、最も感情が昂る「理想の1枚」にフォーカス
- **完全ローカル大容量保存 (IndexedDB):** ブラウザ内蔵Canvasで自動最適化（長辺1600px）し、端末内DBへ安全に格納（サーバー送信ゼロ）
- **トリミング / 全体表示切り替え:** アスペクト比に合わせた表示モードのワンタッチ変更

### 2. 目標・論理領域 (Goal & Perspective)
- **リアルタイム秒単位カウントダウン:** 等幅フォント（`JetBrains Mono`）で残り時間を秒刻みで可視化し、先延ばし癖を防止
- **Why & Motivation メモ:** 「なぜそれを手に入れたいのか」という原動力・感情を常に再確認
- **着眼点・アイデアカード:** TODOリスト特有の「未完了プレッシャー」を排除し、「実現のために何ができるか？」という前向きな視点を並べるカードUI

### 3. 行動心理学に基づく2層目標管理
- **集中枠（Active Deck / 最大10個）:** 同時進行する目標を最大10個に絞り、意識の散漫を防止
- **目標ストック＆定期棚卸し (Backlog & Review):** いつか叶えたい夢を無制限にストック。月1回以上の見直しを促すアラート付きで昇格・温存（退避）を管理

### 4. ブースト機能
- **全画面フォーカス / 瞑想モード:** 余計なUIを消し、理想の写真と言葉だけと対峙する全画面表示
- **1920×1080 壁紙出力 (PNG):** ビジョンボード全体を高解像度画像としてワンクリック生成・ダウンロード
- **JSONバックアップ & 復元:** 端末変更時やバックアップ用のデータ入出力に対応
